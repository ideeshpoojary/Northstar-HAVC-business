# Northstar-HAVC-business

A responsive HVAC service-business website designed to present heating and cooling services, build customer trust, and encourage appointment requests.

## Overview

This project focuses on creating a professional, conversion-oriented website for a local HVAC business. The interface is designed to make services easy to understand while providing clear calls to action throughout the user journey.

## Features

- Responsive layout for desktop, tablet, and mobile
- Service-focused landing page structure
- Service areas section
- Customer reviews and testimonials
- FAQ section
- Before-and-after comparison interaction
- Appointment request interface
- Mobile-friendly navigation
- Clear call-to-action sections

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
